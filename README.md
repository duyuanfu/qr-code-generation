高颜值、全功能、不限扫码次数的现代二维码 Web SaaS 平台。支持文字、网址、电子名片、图片画廊、高清视频流与各类常用文档附件的二维码生成、深度美化与批量作业；另提供 **GIF 动图导出** 与 **商品条形码标签导出** 两条独立工作流。静态码永久有效，动态活码含 **3 个月服务期**（到期续费）。

- **专业级美化与模板引擎**：
  - **几何码点**：经典方块、柔和圆角、圆润点阵、商务流线、大圆角。
  - **寻象码眼**：外框造型与内芯造型独立调配、双色独立着色。

  - **行业预置**：一键套用商业极简、科技霓虹、活力社交、餐饮门店、资产盘点标签模板。
- **批量作业工作台**：
  - **批量生成**：支持 Excel 表格 (`.xlsx/.xls`) 与 CSV 导入，多线程并发渲染，一键打包 ZIP 高清导出。
  - **批量解码**：支持多张图片拖拽、页面截图按 `Ctrl + V` 极速粘贴识别，原生硬件加速 + ZXing 双引擎保障，支持一键将结果导出为 Excel。
- **GIF 动图导出（`/gif`）**：
  - 上传一张海报作背景 + 自己的二维码，服务端合成为 4.68 秒的循环动图，图内自带「截图保存，扫一扫」提示。
  - **前端 Canvas 实时预览**（含倒计时动画、拖动二维码定位、透明度/尺寸/四角淡化调节），不消耗任何额度。
  - 生成前**免费预检**：服务端先渲染末帧并做三档扫码验证，不通过时直接给出建议参数与「一键应用」，一分钱不花。
  - 生成后从成品 GIF 里抽帧**复核可扫性**，全过才核销订单；不可扫会自动抬参数重试（最多 6 次），失败则不扣费。
- **商品条形码标签导出（`/barcode`）**：
  - 支持 **EAN-13 / EAN-8 / UPC-A / Code 128 / Code 39** 五种码制，按**毫米 + DPI** 出图，直接可打印。
  - 校验位自动补全与校验（GS1 mod-10），填错时直接告诉你正确内容与正确位数。
  - **按整数模块像素渲染**，条宽比例严格符合标准 —— 这是激光扫码枪能读出来的前提，也是本页只提供「码制 / 内容 / 尺寸 / DPI」四个参数的原因（不做配色、圆角、Logo、叠图）。
  - 导出并同时给出 **PNG（按所选 DPI 光栅化）+ SVG（矢量，交印刷店）**；PNG 无 alpha 通道，避免打印时白底被合成成浅灰。
  - 参数组合扫不出来时**在付费前就能看到**（预览同时按真实分辨率做两档扫码自检），不会出现「付完钱才报错」。

  - 邮箱注册/登录，`user` / `admin` 双角色，账号可后台禁用。
  - **按二维码类型分别定价**，含体积阶梯加价与服务有效期，见表；管理员终身免费。

- **扫码落地页品牌露出**：所有扫码后打开的页面底部带品牌链接 `Evan 二维码 · http://qr.trythis.pw/`（全屏 PDF 阅读器用右下角浮动样式，不挡内容）。
- **管理后台 `/admin`**：
  - 用户管理、价格配置（按类型分组、体积阶梯、有效期）、收款码配置（多渠道）、订单审核四个面板，全部实时生效。
- **上传安全防线**：后缀黑白名单 + 二进制文件头（Magic Number）嗅探 + 文件名与内容敏感词拦截 + SHA-256 内容去重秒传；单文件上限 500MB，服务端流式落盘不占内存。

## 🚀 本地开发运行

需要 **JDK 17 + Maven + MySQL 8 + Node.js 18+**，以及 **ffmpeg**（GIF 动图导出用，需在 `PATH` 里）。

```bash
# 0. ffmpeg：GIF 导出依赖运行时调用它做两遍调色板编码

cd frontend && npm install && npm run dev
```

## 🐳 服务器生产部署指南（Docker）

针对**服务器上已有其他业务/容器**的环境，本项目通过 `docker-compose.yml` 编排 **MySQL + 后端 + 前端** 三个服务，只对外暴露前端端口，不抢占 80/443。

### 1. 克隆代码到服务器

```bash
git clone https://github.com/duyuanfu/qr-code-generation.git
cd qr-code-generation
```

### 2. 配置环境变量

复制配置模板：
```bash
cp .env.example .env
```
按需修改 `.env`（**以下三项必填，留空则容器无法启动**）：
```ini
APP_PORT=3001                 # 前端对外端口
MYSQL_ROOT_PASSWORD=change-me # 数据库口令，建议随机生成
MYSQL_DATABASE=qr_studio
JWT_SECRET=                   # 至少 32 字节，生成：openssl rand -base64 48
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=               # 首次启动种子化的管理员口令
MOCK_PAY_ENABLED=false        # 生产环境必须 false
UPLOAD_MAX_FILE_SIZE_MB=500   # 单文件上限，需与 Nginx client_max_body_size 一起放大
NEXT_PUBLIC_BRAND_URL=http://qr.trythis.pw/   # 扫码落地页品牌链接
```

> 后端不再内置任何密钥回退值：数据库口令、JWT 密钥、管理员口令只从环境变量读取，
> 缺失时进程直接启动失败。本地开发不用 Docker 时，改用 dev profile 即可获得本地默认值：
> ```bash
> cd backend && mvn spring-boot:run -Dspring-boot.run.profiles=dev
> ```

### 3. 一键启动 Docker 容器

```bash
docker compose up -d --build
```
> - MySQL 数据保存在命名卷 `mysql-data`，上传的文件挂载到宿主机 `./backend/data/uploads`。
> - 后端容器 `depends_on` MySQL 的健康检查，表结构由 `schema.sql` 在启动时幂等创建。
> - 前端镜像构建时通过 `ARG BACKEND_URL` 写入代理目标（rewrites 在构建期固化，运行时改环境变量无效）。
> - **后端镜像底座为 `eclipse-temurin:17-jre-jammy`（非 Alpine），并在构建时 apt 安装 `ffmpeg` + `fontconfig`**，
>   用于 GIF 动图导出。相比原来的 `17-jre-alpine` **镜像大约 170MB**（jammy 底座 + ffmpeg 及其依赖）。
>   - 为什么不能留在 Alpine：musl 下 Java AWT 会报 `Fontconfig head is null`，中文一个字都画不出来，
>     装 `fontconfig` 也无效 —— 这是 Alpine 的 OpenJDK AWT 字体链本身残缺，不是缺包。
>   - 国内构建卡在 `archive.ubuntu.com` 时，改 `docker-compose.yml` 里的 `backend.build.args.APT_MIRROR`
>     （默认已指向阿里云）。若你的网络环境需要代理，也可在这里换成对应私服地址。
>   - 构建期会自动下载约 100MB 的 ffmpeg 依赖，首次 `docker compose build` 慢属正常。

### 4. 绑定域名与反向代理（Nginx / 宝塔面板 / 1Panel）

由于服务器上已有其他服务，建议给该平台分配一个独立二级域名（如 `qr.yourdomain.com`）：

#### 方案 A：使用 Nginx 反向代理
在 Nginx 配置目录（如 `/etc/nginx/conf.d/`）中新建配置文件：
```nginx
server {
    listen 80;
    server_name qr.yourdomain.com; # 替换为您自己的域名

    # 关键：必须 ≥ 后端 UPLOAD_MAX_FILE_SIZE_MB（默认 500MB）+ multipart 开销
    # 若此项小于后端上限，413 会由 Nginx 直接返回 HTML 错误页，前端解析不到 JSON
    client_max_body_size 520M;

    location / {
        # 对应 docker-compose.yml 暴露的宿主机端口
        proxy_pass http://127.0.0.1:3001;
        
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 延长超时时间以支持大文件视频上传
        proxy_connect_timeout 60s;
        proxy_read_timeout 120s;
        proxy_send_timeout 120s;
    }
}
```
保存后重载 Nginx：`nginx -s reload`。

#### 方案 B：使用宝塔面板 / 1Panel
1. 在面板中新建网站，域名输入 `qr.yourdomain.com`。
2. 打开该站点的 **【反向代理】 -> 【添加反向代理】**：
   - 代理名称：`qr-studio`
   - 目标 URL：`http://127.0.0.1:3001`
   - 发送域名：`$host`
3. 在站点配置文件中增加 `client_max_body_size 520M;`（与后端 500MB 上限对齐），并一键申请 Let's Encrypt SSL 证书启用 HTTPS。

## 🎬 GIF 动图导出（`/gif`）

把一张海报当背景、把自己的二维码贴上去，产出一张 4.68 秒的循环动图，图里自带「截图保存，扫一扫」的提示文字。
适合发朋友圈、贴公众号、放进 PPT —— 图本身就能被扫，不用再另外附一张二维码。

**使用流程**

1. 上传**海报背景图**与**二维码图片**（白底即可，服务端会自动把白底抠成透明）。
2. 在左侧 Canvas 预览里拖动二维码调整位置，调尺寸、不透明度、四角淡化程度。
3. 点「预检」—— 服务端渲染末帧并做三档扫码验证，**免费**。不通过时给出建议参数，可一键应用。
4. 点「生成」—— 渲染 117 帧 → ffmpeg 两遍编码 → 从成品 GIF 里抽 5 帧复核 → 落盘核销。约 8 秒。

**几件事要知道**

- **预览是近似效果**，以服务端产物为准（浏览器 Canvas 与 Java2D 的抗锯齿、字体度量有细微差异）。
- **扫码可识别性是硬性验收**。参数太激进的组合会被自动抬回来重试，最多 6 次；
  每次自动调整都会在结果里写明，不会悄悄改掉你设的参数。
- **失败不扣费**。预检失败一分钱不花；生成失败订单保持未核销，改参数可以直接重试。
- 生成属于**一次性导出**（¥3），产物永久可用，没有服务期，也不走活码那套 3 个月到期的逻辑。
- 单次生成较吃 CPU，服务端限流同时只跑 2 个，繁忙时会返回「稍后再试」。

## 🏷️ 商品条形码标签导出（`/barcode`）

把商品的条码号变成一张**按毫米标注、能直接打印**的标签，产出 PNG（按 DPI 光栅化）与 SVG（矢量）。

**使用流程**

1. 选码制：**EAN-13**（零售商品，国内 69 开头）、**EAN-8**（小包装）、**UPC-A**（北美零售）、
   **Code 128**（物流/仓储/资产，可放字母数字）、**Code 39**（老系统、资产标签）。
2. 填内容。EAN/UPC 只需填**前 12 位**（EAN-13）/ 前 7 位（EAN-8）/ 前 11 位（UPC-A），校验位自动补；
   填全码则会逐位校验，错了会直接告诉你正确的那一位。
3. 选标签尺寸（30×20 / 40×25 / 50×30 / 60×40 mm，或自定义）与打印 DPI（203 / 300 / 600）。
4. 预览免费实时刷新，页面上会显示 **实际尺寸 / 每模块像素 / 放大倍率**；
   这组参数如果扫不出来，预览下会写明原因，此时**导出按钮不可点**。
5. 点「导出可打印标签」→ 拿到 PNG（直接打印）+ SVG（交印刷店排版）。

**几件事要知道**

- **请用 300dpi 打印，并选「100% 原大 / 实际大小」**。勾了「适应页面」会让打印机重新缩放，
  条宽比例一歪，激光枪就判不出宽度了。203dpi 是热敏标签机常见规格，能用但容错更低；600dpi 更保险。
- **不要改颜色、不要叠 Logo、不要加圆角。** 激光枪靠边的间距比例判宽度，浅色条、深色底、
  压在条上的图形都会让它读不出来 —— 所以本页干脆不提供这些选项。
- 标签上显示的实际宽度可能比你填的窄一点（比如填 40mm 实际 39.6mm）。这不是 bug：
  条宽必须是整数像素，`40mm × 300dpi = 472px` 除不尽 117 个模块，只能取整。**填窄了会被直接拒绝**，
  并告诉你这个 DPI 下真正可用的宽度区间。
- 贴在不干胶或白纸上。牛皮纸、彩色底、覆亮膜都会拉低对比度，容易读不出。
- 导出属于**一次性计费**（¥2），产物无服务期；参数没通过自检时不会让你付钱，付了之后自检失败也不核销。
